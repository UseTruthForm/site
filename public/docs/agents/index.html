Using TruthForm with agents

An agent that writes infrastructure needs to know what a resource takes before it writes one. TruthForm already reads that from each platform's published schemas to capture and restore, and truthform mcp tells an agent the same thing over the Model Context Protocol.

Read-only, with no restore tool. No tool can change anything in your systems, and none grants access: the permissions tool only says what to grant. Restoring creates and changes live resources, so it stays a command a person runs with the snapshot in front of them.

Add it to a client

The server speaks JSON-RPC on standard input and output, like any local MCP server, and takes no arguments. With truthform on your PATH, add it to a client's configuration:

{"mcpServers": {"truthform": {"command": "truthform", "args": ["mcp"]}}}

It supports MCP protocol revisions 2024-11-05, 2025-03-26, 2025-06-18 and 2025-11-25.

The platforms are aws, azure, gcp, github and cloudflare, plus kubernetes for capture, diff, permissions and check_access. Kubernetes types cannot be described yet, because a cluster's schema is its own.

An example

Asked which fields of an SQS queue are fixed at creation, an agent calls describe_type with platform aws and type AWS::SQS::Queue. The answer marks FifoQueue and QueueName as create-only and Arn and QueueUrl as read-only, with a link to AWS's documentation for the type. The agent knows, before writing anything, that renaming the queue would replace it.

What an agent can and cannot do

  • Nothing it calls writes to your systems. Describing types reads public schemas. Capture, diff and check_access run through the same read-only guard as on the command line, which refuses any request that is not a read before it leaves the machine.
  • Capture writes only a new snapshot. It writes to local disk, and only into a directory that does not exist yet or is empty, so an agent cannot overwrite an existing snapshot such as a baseline.
  • There is no restore tool. This is deliberate, not a gap waiting to be filled.
  • Arguments cannot change what runs. Each tool does one fixed thing. Unknown arguments are dropped, and each value is passed as a single --name=value, so a value such as us-east-2 --update is just an invalid region, not an extra flag.
  • It uses the credentials of the environment it runs in. Start the server with the same read-only access you would give a capture; see Permissions.

Alongside the platforms' own servers

TruthForm says what exists and what each field means. To build or change resources, use the platform's own MCP server next to it; the platforms tool names the ones each provider publishes.
