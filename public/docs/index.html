Documentation

TruthForm is one binary that you run inside your own environment. It reads the live configuration of a Kubernetes cluster, a cloud account or a SaaS organisation into a snapshot of plain YAML, diffs what is running against it, and restores what is missing.

Pre-release. TruthForm is not released yet. These pages describe the current build, so they are accurate for the binary you would run today, limits included.

  • Getting startedInstall, credentials, your first capture, then diff, restore, whole environments, exit codes and known limits.
  • PermissionsWhat to grant on each platform, for capture and for restore separately, and which grants have been verified.
  • Using TruthForm with agentsThe MCP server: its tools, what they can and cannot do, and how to add it to a client.

Platforms

Kubernetes, AWS, Azure, Google Cloud, GitHub and Cloudflare have been run against real systems. On GitHub and Cloudflare that is capture only: restore is proven against simulated APIs. The home page lists what each platform's proof covers.

Setting up access

truthform permissions --platform <platform> writes the grant TruthForm needs as a template, with every command to deploy, verify and remove it, and grants nothing itself. truthform check then says who TruthForm is running as, what that identity holds beyond what it needs, and what it can read, type by type. The permissions page explains each grant.
